Week 8

Introduction

In this tutorial we will investigate likelihood using a simulated FIFA World Cup. The interactive simulator is available below. Your tutor will explain to you how to use it.

The simulator assigns every team a strength between 0 and 100. Stronger teams are more likely to win matches. This is based upon a few different sources (such as SOFAScore, FOTMOB, etc.). Rather than predicting the tournament from the strengths, we will use the observed tournament results to determine which strength value is most supported by the data.

For simplicity (see Homework for more sophisticated models), we will assume that the probability Team 1 wins is

\[ P(\text{Team 1 wins})=\frac{\text{Strength}_1}{\text{Strength}_1+\text{Strength}_2} \]

calculate_loglikelihood <- function(team_name,
                                    strength,
                                    data = matches) {

  data |>
    filter(team == team_name) |>
    mutate(
      p_team_wins =
        strength / (strength + opponent_strength),

      observed_probability =
        if_else(
          winner == team_name,
          p_team_wins,
          1 - p_team_wins
        )
    ) |>
    summarise(
      log_likelihood =
        sum(log(observed_probability))
    ) |>
    pull(log_likelihood)
}

The function returns the log-likelihood of the observed results for a proposed team strength.

NoteQuestion 9

In one or two sentences, explain what a maximum likelihood estimate represents in this example.

ImportantClick for solution

The maximum likelihood estimate is the proposed team strength that makes the observed sequence of wins and losses most likely under the assumed probability model.

It is an estimate based on the observed data and may differ from the strength originally used by the simulator.
